## 1. What data does the bot process?
BOT ᴷᴹᴬ only processes data that Discord provides and that is needed for its features:

- **IDs:** user ID, server ID, channel ID, role ID
- **Server membership:** join / leave time, roles, nickname changes, timeouts
- **Interactions:** slash commands, buttons, select menus and forms you use
- **Moderation data:** warnings, timeouts, mutes, kicks, bans, reasons and moderator notes
- **Community features:** event sign-ups, giveaway entries, coins / minigames, invite tracking (who invited whom)
- **Activity counters:** voice minutes and number of messages per day (only the count)

**The bot does NOT read message content** and does **not** use presence / online status.
Usernames and avatars are not stored. Only the display name shown in an event sign-up list is kept together with that event.

## 2. Why is this data processed?
- Welcome and leave posts
- Role requests and role management
- Event sign-ups and event statistics
- Giveaways and minigames
- Moderation tools and moderation history
- Server logs for the moderation team
- Invite tracking

## 3. How long is data stored?
- **All stored data is encrypted** on the server (AES encryption). Without the secret key it cannot be read.
- **Activity counters, logs, finished events and finished giveaways:** deleted automatically after **90 days**
- **Moderation history** (warnings, notes, bans …): kept as long as the server needs it, or until deletion is requested
- **Coins, event statistics and payout lists:** kept as long as the bot is used on the server
- **Join / leave times (only user ID + time):** kept for the moderation history
- **Tokens and passwords are never stored in backups**

## 4. Who can see the data?
- The **developer** (bot owner)
- The **moderators of the respective server**, inside Discord and in a private moderation dashboard that requires a **Discord login**
- **No data is sold, shared with third parties or used to train AI**

## 5. Website / dashboard login
The moderation dashboard uses the official **Discord login (OAuth2)**.
It only uses your Discord user ID to check whether you are allowed to see the dashboard.

## 6. Your rights / data deletion
You can request information about your data or its deletion at any time:
- by email: **contact@kma-bot.xyz**
- by direct message to the developer **cay.66** on Discord

Requests are handled as fast as possible, at the latest within **30 days**.
Data that a server needs for moderation (e.g. a ban reason) may be kept until the server team agrees to delete it.

## 7. Changes
If this policy changes, the date at the top will be updated.
